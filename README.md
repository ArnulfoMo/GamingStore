# 🎮 Gaming Store

Gaming Store es un proyecto de desarrollo web que consiste en una tienda en línea dedicada a la venta de videojuegos, consolas, accesorios y productos digitales.

El proyecto se desarrolla como parte de la asignatura de **Programación Web**.

## 🛠️ Tecnologías

- PHP 8.5.12
- Laravel 13
- MySQL 8.0
- Bootstrap 5.3.3
- HTML, CSS y JavaScript

## 🚀 Instalación

Clonar el repositorio e instalar las dependencias:

```bash
git clone https://github.com/USUARIO/GamingStoreAPP.git
cd GamingStoreAPP
composer install
npm install
```

Configurar el entorno:

```bash
cp .env.example .env
php artisan key:generate
```

Configurar la conexión a MySQL en `.env` y ejecutar:

```bash
php artisan migrate
```

Iniciar el proyecto:

```bash
php artisan serve
npm run dev
```
